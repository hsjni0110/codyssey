# Python 기초 퀴즈

## 프로젝트 개요

터미널에서 객관식 퀴즈를 풀고, 문제를 등록하고, 최고 기록을 확인하는 Python 콘솔 게임입니다. `Quiz`는 개별 문제를 표현하고, `QuizGame`은 메뉴와 게임 진행, 파일 저장을 관리합니다.

## 퀴즈 주제와 선정 이유

주제는 **Python 기초 문법**입니다. 퀴즈 게임을 구현할 때 사용하는 자료형, 입력 함수, 리스트, 연산자, 함수의 반환값을 문제로 다시 확인할 수 있어 선택했습니다. 기본 퀴즈는 5문제입니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 이 README가 있는 폴더에서 실행합니다. 별도로 설치할 패키지는 없습니다.

```bash
python3 --version
python3 main.py
```

## 기능 목록

| 메뉴 | 기능 |
| --- | --- |
| 1. 퀴즈 풀기 | 등록된 문제를 차례대로 풀고, 문항별 정오답과 전체 정답 수를 확인합니다. |
| 2. 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력해 등록하고 저장합니다. |
| 3. 퀴즈 목록 | 등록된 문제의 번호와 질문을 봅니다. |
| 4. 점수 확인 | 완료한 풀이 중 가장 많이 맞힌 정답 수를 확인합니다. |
| 5. 종료 | 남은 변경사항의 저장을 시도하고 종료합니다. |

메뉴와 정답 번호는 앞뒤 공백을 제거한 뒤 처리합니다. 빈 입력, 숫자가 아닌 입력, 범위를 벗어난 숫자는 안내 후 다시 받습니다. `Ctrl+C`나 입력 스트림 종료 시에도 안내하고 남은 저장을 시도합니다.

## 데이터 파일 설명

`state.json`은 프로젝트 루트, 즉 `main.py`와 같은 폴더에 UTF-8로 저장됩니다. 파일이 없으면 기본 퀴즈 5개로 시작합니다. JSON 구문이나 필드가 손상된 경우 안내 후 기본 상태로 복구합니다. 퀴즈를 추가하거나 최고 기록을 갱신하면 바로 저장을 시도합니다. 쓰기에 실패하면 안내하며, 종료할 때 다시 시도합니다.

```json
{
  "quizzes": [
    {
      "question": "len([10, 20, 30])의 결과는?",
      "choices": ["2", "3", "4", "30"],
      "answer": 2
    }
  ],
  "best_score": 1
}
```

- `quizzes`는 문제 목록입니다. 각 문제에는 문자열 `question`, 문자열 4개의 배열 `choices`, 1부터 4 사이의 정수 `answer`가 있습니다.
- `best_score`는 한 번의 풀이에서 맞힌 최대 문항 수입니다. `null`은 플레이 기록이 없다는 뜻이며, `0`은 모든 문제를 틀린 풀이 기록을 뜻합니다.
- `state.json`은 각 사용자의 진행 상황을 담으므로 Git에서 제외합니다.
